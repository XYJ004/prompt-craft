# 🐛 Bug 调试提示词

## 🎯 适用场景

- 程序报错排查
- 逻辑问题定位
- 性能问题诊断
- 生产事故分析

## 🌟 效果展示

**输入：**
```python
@app.route('/user/<int:id>')
def get_user(id):
    user = User.query.filter_by(id=id).first()
    return jsonify(user.to_dict())

# 错误：AttributeError: 'NoneType' object has no attribute 'to_dict'
```

**输出：**
```
### 🔍 错误分析
- 类型：运行时错误
- 关键信息：user 为 None，说明数据库中未找到该用户

### 🎯 根因推断
1. 用户 ID 不存在 - 可能性 70%
2. 数据库查询失败 - 可能性 20%
3. 数据库连接问题 - 可能性 10%

### 🔬 验证步骤
1. 检查数据库中是否存在该 ID 的用户
2. 添加日志打印 user 变量值
3. 检查数据库连接是否正常

### ✅ 修复方案

**推荐方案：添加空值检查**
```python
@app.route('/user/<int:id>')
def get_user(id):
    user = User.query.filter_by(id=id).first()
    if user is None:
        return jsonify({'error': 'User not found'}), 404
    return jsonify(user.to_dict())
```

### 🛡️ 预防措施
1. 添加单元测试覆盖不存在用户的情况
2. 使用 Flask-RESTful 的资源不存在异常
3. 添加 API 文档说明可能的错误码
```

## 📝 常见 Bug 类型速查

| Bug 类型 | 关键词 | 推荐检查 |
|----------|--------|----------|
| 空指针 | NoneType, undefined, null | 变量初始化、返回值检查 |
| 类型错误 | TypeError, cannot read | 类型检查、类型断言 |
| 异步问题 | Promise, async, await | 异步流程、错误处理 |
| 内存泄漏 | Out of memory, leak | 资源释放、事件监听 |
| 并发问题 | race condition, deadlock | 锁机制、原子操作 |
| 边界情况 | off by one, empty | 边界值测试 |

---

## ⚠️ 注意事项

- 提供完整的错误堆栈
- 说明复现步骤
- 已尝试的方案有助于更快定位
- 敏感信息注意脱敏
