## 🚀 Quick Start

### Option 1: Clone

```bash
git clone https://github.com/XYJ004/prompt-craft.git
cd prompt-craft/prompts
```

### Option 2: Browse Online

Just browse the [prompts/](prompts/) directory on GitHub.

### Option 3: As MCP Server

```json
{
  "mcpServers": {
    "dev-prompts": {
      "command": "npx",
      "args": ["prompt-craft", "mcp"]
    }
  }
}
```
